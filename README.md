# 🚀 Poker Luck Analyzer

Анализатор карточной удачи в покере. Узнайте, где вам везло с картами, а где — нет, и сколько в вашем результате удачи, а сколько — умения. Точный математический анализ истории рук даёт оценку по каждой улице.
*Никакого подключения к интернету — никакая информация от вас никуда не уходит!*

## 📥 Как скачать и запустить

1. Перейдите в раздел **[Releases (Релизы)](../../releases/latest)** справа на этой странице.
2. В блоке **Assets** скачайте архив или файл `ВашаПрограмма.exe`.
3. Распакуйте архив (если это `.zip`) и запустите исполнимый файл.

> ⚠️ **Примечание:** Если Windows SmartScreen выдаёт предупреждение при запуске, нажмите *«Подробнее»* -> *«Выполнить в любом случае»* (так происходит, если у программы нет платного цифрового сертификата разработчика).
